# Contributing

Keep it small: dependable mirroring, understandable status, useful recovery actions.

1. Build using the README.
2. Run Test-UI.ps1 after UI changes and inspect .local/ui-tests.
3. Test engine changes with test_receiver.py, then a real iPhone. State what actually ran.
4. Keep upstream changes in patches with their source revision and rationale.
5. Never commit binaries, device logs, private keys or personal screenshots.

The UI is English. Explain what to do, avoid protocol jargon and never claim a working picture from a control connection alone. Do not add paid services or telemetry.
